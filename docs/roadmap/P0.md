# P0 implementation plan

Tracking issue: #1

## Goal

Extend the current banned-word checker into a faster, auditable daily review workflow.

## Scope

- Batch checking: paste multiple text blocks or import CSV/TXT, with a per-item risk summary.
- History and audit trail: keep each check locally with timestamp, platform and result; allow export.
- Team-shared custom dictionaries: import and export word lists as JSON/TXT.
- One-click replacement suggestions for matched words.

## Acceptance criteria

- A user can check 20+ items in one run and see a summary per item.
- Check history survives a page reload and can be exported.
- Custom dictionaries can be exported and imported without data loss.
- At least the top 20 built-in words have actionable replacement suggestions.

## Suggested files

- `src/lib/detector.ts` — batch wrapper and result grouping
- `src/data/words.ts` — replacement suggestions
- `src/App.tsx` — batch input, history panel and dictionary import/export
- `src/lib/storage.ts` — new local persistence helpers
