# P3 implementation plan

Tracking issue: #4

## Goal

Extend the platform from execution support into planning and growth intelligence.

## Scope

- Topic and hotspot discovery with keyword tracking.
- Viral post structure analysis with reusable patterns.
- AI-assisted drafting that runs through the compliance checker automatically.
- Conversion attribution from content to orders or leads.

## Acceptance criteria

- Users can see a topic list and save tracked keywords.
- A pattern report can be generated from sample posts.
- AI drafts are checked before being shown and can be sent to the editor with one click.
- An attribution report links published content to conversions.

## Suggested files

- `src/views/GrowthView.tsx` — topics, pattern analysis, local draft generation and attribution in one view
- `src/lib/detector.ts` — reused compliance check for generated drafts
- `src/lib/storage.ts` — keyword persistence

## Dependencies

- P0 checker API and P2 analytics data model
