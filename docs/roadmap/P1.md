# P1 implementation plan

Tracking issue: #2

## Goal

Move from text-only checking to a full pre-publish readiness check.

## Scope

- Platform-specific compliance checklist beyond words: image text, hashtags, qualifications and external links.
- Reusable copy templates and a lightweight asset library for covers and materials.
- One-click adaptation of a draft into Xiaohongshu / Douyin / Xianyu tone and length.

## Acceptance criteria

- Each platform has its own checklist with clear pass/fail states.
- Templates and assets can be saved, reused and deleted locally.
- Adaptation keeps the core message and the adapted copy passes the banned-word check.

## Suggested files

- `src/data/checklists.ts` — new platform checklist definitions
- `src/App.tsx` — checklist panel and template manager
- `src/lib/adapter.ts` — new platform copy adaptation helpers

## Dependencies

- P0 dictionary import/export and check history

## Checklist

- [ ] Define checklist items for each platform
- [ ] Build the checklist UI with pass/fail states
- [ ] Add local template save/reuse/delete
- [ ] Implement copy adaptation rules
- [ ] Run adapted copy through the banned-word checker
- [ ] Add tests for checklist and adaptation logic
