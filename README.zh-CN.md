# 运营发布台

[English README](./README.md)

面向内容运营的轻量级发布前自检工作台。当前模块是中文营销文案的**违禁词检测**：所有文本都在浏览器本地处理，不会上传到服务器。

## 功能特性

- **四种平台视图**：通用合规、小红书、抖音、闲鱼。切换平台后自动加载对应规则集。
- **九类内置词库**：广告法极限词、夸大宣传、医疗健康、金融投资、引流诱导、低俗违规，以及小红书/抖音/闲鱼专项词。
- **自定义词库**：一行一个词，最多 1000 行、每词不超过 100 字，保存在浏览器本地。
- **批量检测**：用空行分隔多段文案，或导入 CSV/TXT 文件，逐条查看风险摘要。
- **检测历史**：最近检测记录保存在本机，可回看或导出 CSV。
- **词库导入导出**：自定义词库支持以 JSON/TXT 格式导入和导出。
- **一键替换**：命中词带替换建议时，可一键应用到原文。
- **抗干扰匹配**：检测前统一全角/半角、英文大小写，并忽略空白和常见分隔符。
- **长词优先**：重叠命中时优先展示更长的词，避免重复统计。
- **结果可读**：原文高亮、风险等级、命中次数、首次出现位置和替换建议，并可一键复制检测报告。
- **快捷操作**：在输入框中按 `⌘/Ctrl + Enter` 直接检测。

## 技术栈

- Vite 6
- React 19 + TypeScript
- 纯前端，无后端、无运行时接口调用

## 本地运行

环境要求：Node.js 18 及以上，npm。

```bash
npm install
npm run dev
```

打开 Vite 输出的本地地址（默认 `http://127.0.0.1:5173/`）。

其他命令：

```bash
npm run typecheck   # 仅执行 TypeScript 检查
npm run build       # 类型检查 + 生产构建
npm run preview     # 本地预览构建产物
```

## 维护词库

编辑 `src/data/words.ts`：

- `PLATFORMS`：平台标签页。
- `CATEGORIES`：筛选分类，以及每个分类对哪些平台可见。
- `WORD_BANK`：按分类存放词条。需要展示替换建议时写成 `['违禁词', '建议替换']`，否则直接写字符串即可。

检测引擎会自动读取这些配置，新增词条时无需修改 `detector.ts`。

## 检测原理

1. 输入文本和词库词条都会先归一化：全角转半角、英文字母转小写，并去掉空白、零宽字符和常见分隔符（`-`、`_`、`/`、`·` 等）。
2. 在归一化后的文本中查找每个启用词条的每一次出现，同时保留到原文位置的映射。
3. 命中重叠时长词优先，例如会报告 `全网第一` 而非单独的 `第一`。
4. 按词条汇总次数，并映射回原文进行高亮展示。
